
# Azure Virtual Machine Lab

## Overview
Hands-on Azure project focused on creating and managing a virtual machine in Microsoft Azure.

## What I Built
- Created an Azure Virtual Machine
- Configured the virtual machine settings
- Configured networking and access
- Connected to and managed the virtual machine
- Practiced basic VM management and monitoring

## Azure Services Used
- Azure Virtual Machines
- Azure Virtual Network
- Network Security Groups (NSG)
- Azure Portal

## Skills Practiced
- Virtual machine deployment
- Azure networking
- Access and security configuration
- Resource management
- VM monitoring

## What I Learned
This lab helped me understand how Azure Virtual Machines are deployed, configured, accessed, and managed in a cloud environment.
